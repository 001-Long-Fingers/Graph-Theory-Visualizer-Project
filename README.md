An interactive graph visualization tool built using Python, Tkinter, NetworkX, and Matplotlib.

This project allows users to input custom vertices and edges and instantly visualize the corresponding graph structure through a graphical interface.

---

## Features

* Interactive graph visualization
* Custom vertex and edge input
* Automatic adjacency list construction
* Graph rendering using NetworkX
* GUI built with Tkinter
* Dynamic graph plotting with Matplotlib

---

## Technologies Used

* Python
* Tkinter
* NetworkX
* Matplotlib

---

## Example Input

### Vertices

```text
{1,2,3,4}
```

### Edges

```text
{{1,2},{2,3},{3,4},{4,1},{1,3}}
```

## How to Run

### 1. Clone the repository

```bash
git clone <repository-link>
cd graph-theory-visualizer
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the program

```bash
python main.py
```
